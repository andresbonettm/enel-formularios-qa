# Entorno de Pruebas y Validación de Formularios — Enel Colombia

Este repositorio contiene la suite completa de formularios, landings y componentes saneados para auditoría técnica y cumplimiento legal de **Enel Colombia (`enel.com.co`)**.

---

## 🎯 Vistas y Estructura

* **`/` (Dashboard Principal — Lote 1):** 18 Formularios iniciales auditados (Prioridad 2).
* **`/lote2` (Dashboard Lote 2):** 16 Formularios y Landings nuevas (Prioridad 1 para entrega inmediata).
* **`/formularios/`:** 18 carpetas con archivos `.html` y `.txt` listos para producción.
* **`/formularios_nuevos/`:** 16 carpetas con archivos `.html` y `.txt` listos para Salesforce Marketing Cloud y AEM.
